# Backlog

Ideas recorded for later. **Do not implement** without the product owner's go; when one is
picked up it gets its own phase or feature spec.

- **Challenge ladder module** — only if FICC already runs one; confirm how challenges, acceptance
  deadlines and position swaps work today before designing it.
- **Light / guest fees** — charging for floodlights or guest visits.
- **Payments (Pix)** — tournament entry fees, guest fees, light fees through a Pix provider.
- **WhatsApp notifications** — a `NotificationChannel` for WhatsApp (Business API), next to in-app
  and push.
- **Padel / beach tennis rules** — new `SportRules` implementations (scoring, team sizes) and
  courts with those sports; no code exists for them yet by design.
